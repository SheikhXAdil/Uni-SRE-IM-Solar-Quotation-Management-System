# Solar Quotation Management System

A multidisciplinary academic project focused on the **requirements engineering, system analysis, and business analysis** of a proposed Solar Quotation Management System.

The project was developed by a **four-member team** and explored the same proposed system across two courses: **Software Requirements Engineering (SRE)** and **Introduction to Marketing (IM)**.

> **Project Status:** Conceptual / Documentation-Based
> This repository documents the analysis and planning of the proposed system. No software implementation was developed as part of this project.

---

## Overview

The Solar Quotation Management System was proposed as a solution for organizing and streamlining the quotation process for solar energy products and installations.

Rather than implementing the system, the project focused on understanding the problem domain, identifying stakeholder and system requirements, modeling the proposed solution, and evaluating its business viability.

The project was subsequently reused in **Introduction to Marketing**, where the technical concept was examined from a business and market perspective.

---

## Project Objectives

* Analyze the requirements of a solar quotation management system
* Define the scope and boundaries of the proposed system
* Identify stakeholders and system use cases
* Document functional and non-functional requirements
* Model system behavior and structure using UML and analysis diagrams
* Develop detailed use case descriptions for selected scenarios
* Investigate the market and competitive environment for the proposed product
* Analyze the business potential of the proposed system
* Apply both software engineering and business analysis techniques to the same product concept

---

# Software Requirements Engineering

The primary technical work was completed as part of the **Software Requirements Engineering (SRE)** course.

The main deliverable was a comprehensive **Software Requirements Specification (SRS)** documenting the proposed system.

### SRS Contents

The requirements documentation covers areas including:

* System introduction and description
* Problem definition
* Project scope
* Stakeholders
* Functional requirements
* Non-functional requirements
* System use cases
* Use case descriptions
* System modeling
* Analysis-level modeling
* Supporting diagrams and specifications

### System Modeling

The project included multiple levels of system modeling to represent the proposed system from different perspectives.

These included:

* Class diagram
* High-level use case diagrams
* Detailed use case diagrams
* Use case-specific diagrams
* Analysis-level diagrams
* Sequence diagrams (SD)
* System sequence diagrams (SSD)

Detailed use case descriptions were also prepared for selected scenarios to document the interaction between actors and the proposed system.

# Business Analysis & Marketing

The same Solar Quotation Management System concept was later used as the basis for work in **Introduction to Marketing (IM)**.

The technical concept from the SRE course was examined from a business perspective through the development of a **business plan**.

### Business Plan

The business analysis covered:

* Product description
* Company description
* Market analysis
* Competitor analysis
* SWOT analysis
* Business opportunity evaluation

This provided a second perspective on the same system: moving from **"What should the system do?"** to **"Is this product commercially viable, and what market would it serve?"**
